## Iteration 812: jobs designed from the runtime (GOALS.md 15)

Read for Q36 (3): PL-BEGIN/PL-STAGE start a pipeline and PL-END waits
for its pids and makes the pipefail status; every ending of a script runs
R-BOOT's R-RUN-EXIT before SYS-EXIT; INT and TERM are caught only by a
script with on EXIT, whose safe points the compilers make poll (R-GC?S).
So spawn is PL-END split in two, the job table stopped after R-RUN-EXIT,
and a script that spawns catches the signals as on EXIT's do - or its jobs
outlive it. The design in GOALS.md 15; built next.
